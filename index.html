    05 / PEOPLE

    Community & contributing

    Public members of the organization, and how to add your own work.

    1. Name it by type

      Prefix the repository with its type (table below). The site files it into the right category automatically.

    2. Write a one-line description

      The description is what people search. Put the venue in it (for example "ICCV 2025") and the site adds a venue badge.

    3. Open it to the community

      Transfer or fork it into the organization, or open an issue in the hub repo. Add the topic website-hide to keep a repo off this page.
